# CondoPilot AI — Hero / Product Presentation Brief

## Product

CondoPilot AI is an AI-agent platform that demonstrates how a digital condominium assistant can understand requests, use controlled tools, execute business operations, and expose its reasoning trace as observable execution steps.

## Hero statement

**An AI agent that doesn't just answer. It acts.**

## Supporting statement

CondoPilot AI combines conversational AI, secure business tools, workflow execution, observability and a polished SaaS interface in one production-oriented demonstration.

## Primary visual direction

- premium SaaS;
- dark-first interface;
- deep navy/indigo base;
- violet/blue/cyan gradient accents;
- soft glass surfaces;
- subtle grid/noise background;
- restrained glow;
- high contrast typography;
- rounded cards;
- smooth micro-interactions;
- purposeful motion.

## Motion principles

Use animation to communicate:

- state changes;
- agent execution;
- loading;
- navigation;
- hierarchy.

Avoid decorative animation that reduces readability.

Preferred:

- 150–250ms micro transitions;
- 250–450ms panel transitions;
- spring-like entrance for key agent events;
- staggered execution trace;
- reduced-motion support.

## Demo moment

The hero demo should show:

User:
"Quais moradores estão inadimplentes?"

Agent:

1. validates request;
2. identifies intent;
3. checks permission;
4. calls `getResidentsInDebt`;
5. validates tool result;
6. generates answer;
7. records execution trace.

Second demo:
"Reserve o salão para Carlos amanhã às 19h."

The UI should visibly show the agent checking availability and requiring confirmation before a high-impact action when applicable.

## Marketing constraints

Never claim that the product is production-ready unless all defined release gates have actually passed.

Never fabricate performance, security, accuracy, cost or customer numbers.
