# CondoPilot Feature Roadmap

Use one feature directory per meaningful capability.

## R01 — Foundation
Auth, tenancy, database, design system, application shell.

## R02 — Agent Core
Agent runtime, model adapter, tool registry, policies, traces.

## R03 — Residents
Resident CRUD/read flows with authorization and tenant isolation.

## R04 — Financial
Delinquency lookup and financial visibility rules.

## R05 — Reservations
Availability, creation, cancellation, confirmation and conflict handling.

## R06 — Notifications
Notification simulation and audit trail.

## R07 — Agent Playground
Conversation UI, tool execution animation and trace details.

## R08 — Security Center
Security events, denied actions, rate-limit visibility and quality indicators.

## R09 — Quality Center
Test status and release-gate presentation.

## R10 — Landing / Marketing
Premium public landing page and demo-oriented storytelling.

## R11 — Final Demo
Seeded scenario, clean environment, screenshots and video.

For a large feature, use Spec Kit's "spec of specs" decomposition approach rather than trying to implement the whole product in one enormous pass.
